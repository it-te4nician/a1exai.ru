Агенту не нужны все 200 схем инструментов

LLM · Agents · 23 ноября 2026 · 1 мин

Google на этой неделе выпустил Tool Retrieval для Gemini API (preview): API сам выбирает нужное подмножество инструментов под запрос. Токенов меньше, модель не мечется между десятками одинаковых схем.

По сути это RAG для описаний инструментов, эмбеддинги давно решили ту же задачу у документов.

Паттерн переносится на любой API: описания в векторный индекс, на запрос достаёте top-k и прикрепляете только их. Нет нужного — ретрай с более широким поиском или весь список.

Два момента. Описания теперь документы для поиска, пишите их под запросы. И коллизии: два похожих инструмента в одном индексе, тихо победит не тот.

Моё правило: до ~20 инструментов шлите все, дальше это retrieval со своей оценкой. И главный выигрыш не токены, а точность: из 10 релевантных сбоит куда реже, чем из 200.
