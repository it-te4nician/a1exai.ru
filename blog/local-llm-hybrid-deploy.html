Локальные LLM — уже не хобби, а вариант деплоя

LLM · LocalLLM · 25 ноября 2026 · 1 мин

Три сигнала за неделю: llama.cpp доехала до v1.0.0, Edge0 показала 145B-модель, которая работает локально, Apple выпустила Foundation Models для инференса на устройстве.

Короче, все трое об одном: держать модели у себя — уже вариант деплоя.

Local берёт периметром (для чувствительных данных это решает всё), фиксированной ценой вместо per-token и контролем над латентностью и rate limits.

API берёт качеством (frontier-модели всё ещё в облаке), плюс ноль железа и эластичность на пиках.

Ловушка — выбрать сторону для всего. Только local: слабые модели на сложных задачах. Только API: приватные данные уходят вендору и платишь за каждый чих.

Моё мнение: hybrid с первого дня. Local — чувствительное и простое в объёме, API — сложные 10%.

Лучше разложить нагрузку сейчас, чем это сделает следующий релиз.
