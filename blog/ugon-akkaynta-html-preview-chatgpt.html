Угон аккаунта через HTML-превью в ChatGPT

Security · Prompt Injection · 7 ноября 2026 · 1 мин

Разобрал write-up Parameter Labs: атаковали artifacts, HTML-приложения в sandbox-превью. Дошло до угона аккаунта.

Урок шире этого бага. Рендеришь вывод модели, значит отдаёшь контент, за который она не отвечает. На него влияет всё, что модель успела прочитать: страница по ссылке, документ, ответ инструмента. Так prompt injection становится content injection.

Если генерируешь UI моделью:

  • контент от модели на отдельный origin, без общих cookies и localStorage
  • iframe sandbox без allow-same-origin плюс строгий CSP
  • retrieval и tool results это input, а не инструкции
  • и заранее проверь, до чего модель может дотянуться

Честно: формы валидируем тщательно, вывод модели шипим без проверок. Эта асимметрия и есть главная уязвимость. LLM output это user input, который набрал себя сам.
