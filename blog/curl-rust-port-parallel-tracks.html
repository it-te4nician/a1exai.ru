Порт curl на Rust: работа на боковой дорожке

Rust · curl · 25 ноября 2026 · 1 мин

185 000 строк C стали 340 000 строк Rust за три с небольшим недели. Параллельно проект смержил 300+ коммитов и закрыл около 200 багфиксов. Юзеры ничего не заметили.

Это Даниэль Стенберг про агентский порт curl, цитирует Саймон Уиллисон.

Цифры не столько про скорость, сколько про структуру. Две дорожки шли параллельно: агентская тащила объём без релизного давления, мейнлайн жил в обычном ритме.

По сути, схема повторяемая. Механическая проверяемая работа (порты, миграции, boilerplate) идёт на боковую дорожку. Между дорожками верификация: тесты, type check, ревью диффа. Что нельзя дёшево проверить, не параллелят. Сгенерённые строки становятся активом, только пройдя ревью и обычный коммит.

Честно говоря, 340к строк сами по себе не впечатляют. Интереснее, какие части проекта можно увести на боковую. Вот с них и начну.
